\# Задание task2 - Прототип базы данных (in-memory)



\## Структура проекта

\- database.py - класс Table с методами работы с данными

\- main.py - консольный интерфейс пользователя



\## Функциональность

\- Добавление студентов (имя, группа, средний балл)

\- Просмотр всех записей

\- Поиск по ID, имени, группе, баллу

\- Поиск по нескольким полям одновременно

\- Обработка ошибок ввода
